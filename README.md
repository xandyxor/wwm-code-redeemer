# 燕雲十六聲序號兌換助手 v1.9

雙擊 **Start.cmd** 啟動。不需安裝 Python 或其他套件。啟動器會比對遊戲與工具的權限；需要管理員權限時，請自行完成 Windows 管理員確認。

v1.9 將游標移動改為約 240 毫秒、20 個連續位置的平滑移動，起步與到達時較慢。已接近目標時只做短距離調整；移動中切走遊戲或按 F8 會停止。入口、輸入框、移開輸入焦點和「只測 A」都使用此方式。這是操作呈現的調整，不能保證避免停權，也不代表遊戲允許自動兌換工具。

v1.7 修正 Windows PowerShell 不支援 `[ushort]` 別名造成的確認／取消錯誤，改用 `System.UInt16`，並加入實際快捷鍵流程的回歸測試。工具也會阻止重複開啟；升級時請先關閉所有舊助手視窗，釋放熱鍵。`Win32=1409` 表示該全域熱鍵已被占用；若關閉舊工具後仍出現，請檢查其他程式的快捷鍵。

## 使用方式

1. 遊戲使用視窗化或無邊框模式，進入「設定 → 其他」。
2. 按「讀取網站序號」，或自行貼上序號，每行一組。來源為 [codes.yar.gg](https://codes.yar.gg/) 的有效清單，會去重並排除已明確到期的項目。
3. 在「紀錄名稱」下拉選擇帳號；新帳號可直接輸入名稱，按「記住名稱」保存。開始兌換或正常關閉工具時也會保存。不同遊戲帳號請使用不同名稱。
4. 校準 **A 兌換碼入口**：在兌換視窗關閉時按 A，8 秒內切回遊戲，把滑鼠停在兌換碼右側箭頭，等候自動記住。F6 可以提前擷取。
5. 手動打開兌換視窗，校準 **B 序號輸入框**。同樣按 B 後，8 秒內把滑鼠停在輸入框中央。
6. 按 F9 開始。可以停在「其他」頁，也可以讓輸入框保持開啟。預設只嘗試一筆，確認正常後再勾選「連續嘗試」。

**只需要 A、B 兩個滑鼠位置。** 預設點輸入框、Ctrl+A 全選、直接貼上整組序號，再點輸入框上方空白處，最後按 Space 確認。按 Esc 取消前也會先點空白處，讓輸入框失去焦點。不必校準確認／取消按鈕或額外的空白位置；空白點依 B 與視窗大小計算。校準時會保存設定頁與輸入框的畫面樣本，用來判斷目前在哪個畫面。

## 加速方式

- 預設送出間隔 **1 秒**，可用 0.1 秒為單位調整至 **0.1～60 秒**，不再有隱藏的 3.2 秒下限。清空、貼上與畫面判斷都在間隔內進行。
- 結果觀察時間也會隨間隔縮短，不會在 1 秒模式仍固定等 900 毫秒。實際送出速度仍受遊戲回應、點擊與畫面檢查耗時影響；設定 0.1 秒不保證每秒能送出十筆。遊戲若顯示操作太頻繁，可調高間隔。
- 輸入框仍開著時，直接清掉舊碼、換下一碼，省去反覆取消與重開。最後一筆或單筆測試完成時，才按 Esc 關閉。
- 預設使用 Ctrl+A 及剪貼簿一次替換整組序號，省去逐字清空和輸入。
- 「相容模式：逐字輸入」預設關閉，貼上不適用時才需勾選。過程中仍可按 F8 暫停。

從 v1.5 升級後預設改成直接貼上；之後會記住你選擇的輸入方式、間隔與連續模式。

v1.8 首次啟動預設改成 1 秒，之後記住你選擇的間隔。帳號列表會合併已儲存名稱、上次使用的名稱及既有兌換紀錄中的名稱，不必重新逐一輸入。選擇不同名稱時，略過已嘗試序號的判斷仍依該名稱分開處理。

## 熱鍵與暫停

| 熱鍵 | 功能 |
| --- | --- |
| F6 | 提前記住正在校準的滑鼠位置 |
| F9 | 開始／繼續 |
| F8 | 全域暫停 |
| Space | 工具送出確認 |
| Esc | 遊戲取消；不再兼作工具暫停鍵 |

工具開啟時會註冊 F6、F8、F9，關閉時釋放。熱鍵被占用會顯示在介面上；校準仍可使用免按鍵倒數，啟動仍可按介面上的「開始」。請先關閉舊工具再開新版。

切換到其他視窗、遊戲關閉或尺寸改變時會暫停。重新啟動工具／遊戲、改變解析度或介面縮放後需重新校準 A、B；移動相同尺寸的遊戲視窗不需要。恢復時可停在設定頁或兌換輸入框。

## 位置與結果

「只測 A（移動、不點擊）」可單獨檢查入口位置，不會輸入或送出序號。紀錄中會顯示目標、游標讀回位置、差值及限制範圍。

工具會辨識設定頁與兌換輸入框，且在送出 Space／Esc 前再次確認遊戲焦點及畫面。**它不讀取提示文字，紀錄的「已嘗試」不等於兌換成功。** 實際獎勵請查看遊戲與信箱。無法辨識畫面時會停止，入口沒打開時最多重試一次。

## 本機資料

- `data/attempts.jsonl`：依紀錄名稱保存已嘗試的序號。預設略過已嘗試項目；要重試可取消勾選「略過此名稱已嘗試的序號」。
- `data/settings.json`：帳號名稱列表、上次選擇的名稱、輸入方式、送出間隔與連續模式。點位及畫面樣本只保留於目前執行期間。
- 貼上模式暫時使用剪貼簿，暫停或正常結束時會嘗試還原。若中途自行複製其他內容，會保留新的內容。

資料只寫在本機，沒有遊戲帳密欄位。流程設計曾參考 [yunyi-zhao/yanyun-code-autofill](https://github.com/yunyi-zhao/yanyun-code-autofill)，本版依使用者實測改用 Space／Esc。

## 驗證

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Test-Core.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\Test-Native.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Launch.ps1 -SelfTest
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\Redeem.ps1 -SelfTest
```

測試涵蓋序號解析、帳號紀錄、結果流程、入口重試、送出節奏、兩點校準、輸入框重用、最後才取消，以及介面建構。

要驗證實際滑鼠、文字、Space 與 Esc 輸入，可執行下列指令，在新開的測試視窗按「Run input test」。它只操作測試視窗；完成後應顯示 PASSED。

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\Test-Native.ps1 -InputTest
```
